Warm-upEpisode 2 · The Second Derivative
1. Differentiate $f(x)=(x^{2}-2)e^{-5x}$. Give $f'(x)$ with the common factor $e^{-5x}$ taken out.
The function is a product, so use the product rule.
$u=x^{2}-2,\quad u'=2x$
$v=e^{-5x},\quad v'=-5e^{-5x}$
$f'(x)=2x\,e^{-5x}-5(x^{2}-2)e^{-5x}$
Both terms contain $e^{-5x}$, so take it out.
$f'(x)=e^{-5x}(2x-5x^{2}+10)$
$\phantom{f'(x)}=e^{-5x}(-5x^{2}+2x+10)$
2. Solve $e^{4x}(5x^{2}-7x)=6e^{4x}$.
$e^{4x}>0$ for every $x$, so divide both sides by $e^{4x}$.
$5x^{2}-7x=6$
$5x^{2}-7x-6=0$
$(5x+3)(x-2)=0$
$x=2$ or $x=-\dfrac{3}{5}$
FactEpisode 2 · The Second Derivative
The second derivative
$f''(x)=\dfrac{d}{dx}(f'(x))$
$\dfrac{d^{2}y}{dx^{2}}=\dfrac{d}{dx}\left(\dfrac{dy}{dx}\right)$
Differentiate twice. $\dfrac{d^{2}y}{dx^{2}}$ is also written $y''$.

Find $\dfrac{d^{2}y}{dx^{2}}$, where $y=e^{6x}+x^{5}-8x^{4}$.
$\dfrac{dy}{dx}=6e^{6x}+5x^{4}-32x^{3}$
The second derivative is the derivative of $\dfrac{dy}{dx}$.
$\dfrac{d^{2}y}{dx^{2}}=\dfrac{d}{dx}\left(\dfrac{dy}{dx}\right)$
$\phantom{\dfrac{d^{2}y}{dx^{2}}}=\dfrac{d}{dx}(6e^{6x}+5x^{4}-32x^{3})$
$\phantom{\dfrac{d^{2}y}{dx^{2}}}=36e^{6x}+20x^{3}-96x^{2}$
I Do 2Episode 2 · The Second Derivative
Find the values of $x$ for which $f''(x)=7e^{-3x}$, where $f(x)=x^{2}e^{-3x}$.
Last operation: multiplied, so the product rule.
$u=x^{2}$, $u'=2x$; $v=e^{-3x}$, $v'=-3e^{-3x}$
$f'(x)=2xe^{-3x}-3x^{2}e^{-3x}$
Common factor $e^{-3x}$ only, because $f'(x)$ is differentiated again.
$f'(x)=e^{-3x}(2x-3x^{2})$
$f''(x)$ is the derivative of $f'(x)$. $f'(x)$ is a product, so the product rule again.
$u=e^{-3x}$, $u'=-3e^{-3x}$; $v=2x-3x^{2}$, $v'=2-6x$
$f''(x)=-3e^{-3x}(2x-3x^{2})+e^{-3x}(2-6x)$
$\phantom{f''(x)}=e^{-3x}(-6x+9x^{2}+2-6x)$
$\phantom{f''(x)}=e^{-3x}(9x^{2}-12x+2)$
Set $f''(x)=7e^{-3x}$.
$e^{-3x}(9x^{2}-12x+2)=7e^{-3x}$
$e^{-3x}>0$ for every $x$, so divide both sides by $e^{-3x}$.
$9x^{2}-12x+2=7$
$9x^{2}-12x-5=0$
$(3x-5)(3x+1)=0$
$x=\dfrac{5}{3}$ or $x=-\dfrac{1}{3}$
We Do 1Episode 2 · The Second Derivative
Find the values of $x$ for which $f''(x)=-e^{-x}$, where $f(x)=x^{2}e^{-x}$.
Last operation: multiplied, so the product rule.
$u=x^{2}$, $u'=2x$; $v=e^{-x}$, $v'=-e^{-x}$
$f'(x)=2xe^{-x}-x^{2}e^{-x}$
Common factor $e^{-x}$ only, because $f'(x)$ is differentiated again.
$f'(x)=e^{-x}(2x-x^{2})$
$f''(x)$ is the derivative of $f'(x)$. $f'(x)$ is a product, so the product rule again.
$u=e^{-x}$, $u'=-e^{-x}$; $v=2x-x^{2}$, $v'=2-2x$
$f''(x)=-e^{-x}(2x-x^{2})+e^{-x}(2-2x)$
$\phantom{f''(x)}=e^{-x}(-2x+x^{2}+2-2x)$
$\phantom{f''(x)}=e^{-x}(x^{2}-4x+2)$
Set $f''(x)=-e^{-x}$.
$e^{-x}(x^{2}-4x+2)=-e^{-x}$
$e^{-x}>0$ for every $x$, so divide both sides by $e^{-x}$.
$x^{2}-4x+2=-1$
$x^{2}-4x+3=0$
$(x-1)(x-3)=0$
$x=1$ or $x=3$
We Do 2Episode 2 · The Second Derivative
Find the values of $x$ for which $f''(x)=5e^{2x}$, where $f(x)=(x^{2}-3x)e^{2x}$.
Last operation: multiplied, so the product rule.
$u=x^{2}-3x$, $u'=2x-3$; $v=e^{2x}$, $v'=2e^{2x}$
$f'(x)=(2x-3)e^{2x}+2(x^{2}-3x)e^{2x}$
Common factor $e^{2x}$ only, because $f'(x)$ is differentiated again.
$f'(x)=e^{2x}(2x-3+2x^{2}-6x)$
$\phantom{f'(x)}=e^{2x}(2x^{2}-4x-3)$
$f''(x)$ is the derivative of $f'(x)$. $f'(x)$ is a product, so the product rule again.
$u=e^{2x}$, $u'=2e^{2x}$; $v=2x^{2}-4x-3$, $v'=4x-4$
$f''(x)=2e^{2x}(2x^{2}-4x-3)+e^{2x}(4x-4)$
$\phantom{f''(x)}=e^{2x}(4x^{2}-8x-6+4x-4)$
$\phantom{f''(x)}=e^{2x}(4x^{2}-4x-10)$
Set $f''(x)=5e^{2x}$.
$e^{2x}(4x^{2}-4x-10)=5e^{2x}$
$e^{2x}>0$ for every $x$, so divide both sides by $e^{2x}$.
$4x^{2}-4x-10=5$
$4x^{2}-4x-15=0$
$(2x-5)(2x+3)=0$
$x=\dfrac{5}{2}$ or $x=-\dfrac{3}{2}$
We Do 3Episode 2 · The Second Derivative
Let $f(x)=xe^{-4x}$. Show that $f''(x)=8(2x-1)e^{-4x}$.
Last operation: multiplied, so the product rule.
$u=x$, $u'=1$; $v=e^{-4x}$, $v'=-4e^{-4x}$
$f'(x)=e^{-4x}-4xe^{-4x}$
Common factor $e^{-4x}$ only, because $f'(x)$ is differentiated again.
$f'(x)=e^{-4x}(1-4x)$
$f''(x)$ is the derivative of $f'(x)$. $f'(x)$ is a product, so the product rule again.
$u=e^{-4x}$, $u'=-4e^{-4x}$; $v=1-4x$, $v'=-4$
$f''(x)=-4e^{-4x}(1-4x)+e^{-4x}\times(-4)$
$\phantom{f''(x)}=e^{-4x}(-4+16x-4)$
$\phantom{f''(x)}=e^{-4x}(16x-8)$
Common factor $8$.
$\phantom{f''(x)}=8(2x-1)e^{-4x}$
