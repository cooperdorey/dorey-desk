1. Solve $4x^{4}-9x^{2}=0$.
Common factor first: $x^{2}$.
$x^{2}(4x^{2}-9)=0$
$x^{2}(2x-3)(2x+3)=0$ (difference of two squares)
Dividing by $x^{2}$ would lose the root $x=0$.
$x=0$, $x=\tfrac32$ or $x=-\tfrac32$
2. Find $g(-2)$ for $g(x)=x^{5}-3x^{3}+4$.
$g(-2)=(-2)^{5}-3\times(-2)^{3}+4$
$\phantom{g(-2)}=-32-3\times(-8)+4$
$\phantom{g(-2)}=-32+24+4$
$\phantom{g(-2)}=-4$

Find the stationary points of $f(x)=2x^{3}-6x+7$.
Differentiate each term.
$f'(x)=6x^{2}-6$
Common factor $6$ first.
$\phantom{f'(x)}=6(x^{2}-1)$
Difference of two squares.
$\phantom{f'(x)}=6(x-1)(x+1)$
The tangent is horizontal where $f'(x)=0$.
$6(x-1)(x+1)=0$
$x=1$ or $x=-1$
A stationary point is a point, so it needs both coordinates. Substitute into $f(x)$, not $f'(x)$.
$f(1)=2\times1-6\times1+7=3$
$f(-1)=2\times(-1)-6\times(-1)+7=-2+6+7=11$
The stationary points are $(1,\,3)$ and $(-1,\,11)$.

Find the stationary points of $f(x)=3x^{5}-5x^{3}+4$ and, by testing the sign of $f'(x)$ on either side of each, determine their nature.
Differentiate each term.
$f'(x)=15x^{4}-15x^{2}$
Common factor $15x^{2}$ first.
$\phantom{f'(x)}=15x^{2}(x^{2}-1)$
Difference of two squares.
$\phantom{f'(x)}=15x^{2}(x-1)(x+1)$
Stationary points are where $f'(x)=0$.
$15x^{2}(x-1)(x+1)=0$
Solve the factors as they stand. Dividing by $x^{2}$ would lose the root $x=0$.
$x=-1$, $x=0$ or $x=1$
Each stationary point needs both coordinates. Substitute into $f(x)$, not $f'(x)$.
$f(-1)=3\times(-1)^{5}-5\times(-1)^{3}+4=-3+5+4=6$
$f(0)=4$
$f(1)=3-5+4=2$
The roots split the number line into four intervals. Test one value strictly inside each, so no test value passes the next stationary point.
The factor $15x^{2}$ is never negative, so only $(x-1)(x+1)$ decides the sign.
$f'(-2)=15\times4\times(-3)\times(-1)=180>0$
$f'\left(-\tfrac12\right)=15\times\tfrac14\times\left(-\tfrac32\right)\times\tfrac12<0$
$f'\left(\tfrac12\right)=15\times\tfrac14\times\left(-\tfrac12\right)\times\tfrac32<0$
$f'(2)=15\times4\times1\times3=180>0$
Record the signs in a sign table.
$x:\quad -2\quad -1\quad -\tfrac12\quad 0\quad \tfrac12\quad 1\quad 2$
$f'(x):\quad +\quad 0\quad -\quad 0\quad -\quad 0\quad +$
Name each point by the signs either side. Test every point, since a sign may not change.
At $x=-1$ the sign goes $+$ to $-$, so a local maximum.
At $x=0$ the sign goes $-$ to $-$, so a horizontal point of inflection.
At $x=1$ the sign goes $-$ to $+$, so a local minimum.
The local maximum is $(-1,\,6)$, the horizontal point of inflection is $(0,\,4)$ and the local minimum is $(1,\,2)$.

Find the stationary points of $f(x)=x^{3}e^{-4x}$ and, by testing the sign of $f'(x)$ on either side of each, determine their nature.
Last operation: multiplied, so the product rule.
$u=x^{3}$, $u'=3x^{2}$; $v=e^{-4x}$, $v'=-4e^{-4x}$
$f'(x)=3x^{2}e^{-4x}-4x^{3}e^{-4x}$
Common factor $x^{2}e^{-4x}$ first.
$\phantom{f'(x)}=x^{2}(3-4x)e^{-4x}$
Stationary points are where $f'(x)=0$.
$x^{2}(3-4x)e^{-4x}=0$
$e^{-4x}>0$ for all $x$, so it is never a root.
Solve the factors as they stand. Dividing by $x^{2}$ would lose the root $x=0$.
$x=0$ or $x=\tfrac34$
Each stationary point needs both coordinates. Substitute into $f(x)$, not $f'(x)$.
$f(0)=0$
$f\left(\tfrac34\right)=\left(\tfrac34\right)^{3}e^{-3}=\tfrac{27}{64}e^{-3}$
The roots split the number line into three intervals. Test one value strictly inside each.
$e^{-4x}>0$, so it never decides the sign. The factor $x^{2}$ is never negative, so only $(3-4x)$ decides.
$f'(-1)=1\times7\times e^{4}>0$
$f'\left(\tfrac12\right)=\tfrac14\times1\times e^{-2}>0$
$f'(1)=1\times(-1)\times e^{-4}<0$
Record the signs in a sign table.
$x:\quad -1\quad 0\quad \tfrac12\quad \tfrac34\quad 1$
$f'(x):\quad +\quad 0\quad +\quad 0\quad -$
Name each point by the signs either side. Test every point, since a sign may not change.
At $x=0$ the sign goes $+$ to $+$, so a horizontal point of inflection.
At $x=\tfrac34$ the sign goes $+$ to $-$, so a local maximum.
The horizontal point of inflection is $(0,\,0)$ and the local maximum is $\left(\tfrac34,\,\tfrac{27}{64}e^{-3}\right)$.
We Do 3Episode 3 · Stationary Points and the First Derivative Test
Let $f(x)=\dfrac{e^{3x}}{x^{2}}$, for $x>0$.
(a) Show that $f'(x)=\dfrac{(3x-2)e^{3x}}{x^{3}}$. (2 marks)
Last operation: divided, so the quotient rule.
$u=e^{3x}$, $u'=3e^{3x}$; $v=x^{2}$, $v'=2x$
$f'(x)=\dfrac{u'v-uv'}{v^{2}}$
$\phantom{f'(x)}=\dfrac{3e^{3x}\cdot x^{2}-e^{3x}\cdot2x}{x^{4}}$
Common factor $xe^{3x}$.
$\phantom{f'(x)}=\dfrac{xe^{3x}(3x-2)}{x^{4}}$
Cancel one factor of $x$.
$\phantom{f'(x)}=\dfrac{(3x-2)e^{3x}}{x^{3}}$
(b) Hence find the stationary point and, by testing the sign of $f'(x)$ on either side, determine its nature. (3 marks)
From (a), stationary points are where $f'(x)=0$.
$\dfrac{(3x-2)e^{3x}}{x^{3}}=0$
$e^{3x}>0$ and $x^{3}>0$ for $x>0$, so only $3x-2$ can be zero.
$x=\tfrac23$
A stationary point needs both coordinates. Substitute into $f(x)$, not $f'(x)$.
$f\left(\tfrac23\right)=\dfrac{e^{2}}{\left(\tfrac23\right)^{2}}=\dfrac{e^{2}}{\tfrac49}=\tfrac94e^{2}$
The domain is $x>0$, giving two intervals. Test one value strictly inside each.
$e^{3x}>0$ and $x^{3}>0$, so they never decide the sign. Only $3x-2$ decides.
$x=\tfrac13$: $3\times\tfrac13-2=-1<0$, so $f'\left(\tfrac13\right)<0$
$x=1$: $3\times1-2=1>0$, so $f'(1)>0$
Record the signs in a sign table.
$x:\quad \tfrac13\quad \tfrac23\quad 1$
$f'(x):\quad -\quad 0\quad +$
Name each point by the signs either side.
At $x=\tfrac23$ the sign goes $-$ to $+$, so a local minimum.
The stationary point is $\left(\tfrac23,\,\tfrac94e^{2}\right)$, a local minimum.
