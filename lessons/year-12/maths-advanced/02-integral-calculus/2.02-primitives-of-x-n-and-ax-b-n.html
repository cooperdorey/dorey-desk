FactEpisode 2 · Primitive functions
Reverse power rule
$\displaystyle\int x^{n}\,dx=\dfrac{1}{n+1}x^{n+1}+c,\quad n\neq-1$
I DoEpisode 2 · Primitive functions
Find $\displaystyle\int\left(6x^{2}-\dfrac{8}{x^{3}}\right)dx$.
Rewrite: $\int\left(6x^{2}-8x^{-3}\right)dx$
$=\dfrac{6x^{3}}{3}-\dfrac{8x^{-2}}{-2}+c$
$=2x^{3}+4x^{-2}+c$
$=2x^{3}+\dfrac{4}{x^{2}}+c$
Check: $\dfrac{d}{dx}\left(2x^{3}+4x^{-2}\right)=6x^{2}-8x^{-3}$
We Do 1Episode 2 · Primitive functions
Find $\displaystyle\int\left(\sqrt{x}+x^{2}\right)dx$.
Rewrite: $\int\left(x^{\frac{1}{2}}+x^{2}\right)dx$
$=\dfrac{x^{\frac{3}{2}}}{\frac{3}{2}}+\dfrac{x^{3}}{3}+c$
$=\tfrac{2}{3}x^{\frac{3}{2}}+\tfrac{1}{3}x^{3}+c$

FactEpisode 2 · Primitive functions
Linear inside
$\displaystyle\int(ax+b)^{n}\,dx=\dfrac{1}{a(n+1)}(ax+b)^{n+1}+c,\quad n\neq-1,\ a\neq0$
ProofEpisode 2 · Primitive functions
Linear inside
Differentiate the right-hand side.
$\dfrac{d}{dx}\left[\dfrac{1}{a(n+1)}(ax+b)^{n+1}\right]=\dfrac{1}{a(n+1)}\times(n+1)(ax+b)^{n}\times a$
$=(ax+b)^{n}$
So it is a primitive of $(ax+b)^{n}$.
I DoEpisode 2 · Primitive functions
Find $\displaystyle\int(3x-2)^{4}\,dx$.
$a=3$ and $n+1=5$, so divide by $3\times5=15$.
$\int(3x-2)^{4}\,dx=\dfrac{(3x-2)^{5}}{15}+c$
Check: $\dfrac{d}{dx}\dfrac{(3x-2)^{5}}{15}=\dfrac{5(3x-2)^{4}\times3}{15}=(3x-2)^{4}$
We Do 3Episode 2 · Primitive functions
Find $\displaystyle\int\dfrac{6}{(3x-2)^{2}}\,dx$.
Rewrite: $\int6(3x-2)^{-2}\,dx$
$a=3$ and $n+1=-1$, so divide by $3\times(-1)=-3$.
$=\dfrac{6(3x-2)^{-1}}{-3}+c$
$=-\dfrac{2}{3x-2}+c$
We Do 4Episode 2 · Primitive functions
Find $\displaystyle\int\dfrac{1}{(2x+1)^{2}}\,dx$.
Rewrite: $\int(2x+1)^{-2}\,dx$
$a=2$ and $n+1=-1$, so divide by $2\times(-1)=-2$.
$=\dfrac{(2x+1)^{-1}}{-2}+c$
$=-\dfrac{1}{2(2x+1)}+c$
