FactEpisode 12 · The trapezoidal rule
$\displaystyle\int_{a}^{b}f(x)\,dx\approx\dfrac{b-a}{2n}\{f(a)+f(b)+2[f(x_{1})+\cdots+f(x_{n-1})]\}$
where $a=x_{0}$ and $b=x_{n}$
ProofEpisode 12 · The trapezoidal rule
Each strip has width $h=\dfrac{b-a}{n}$, so $\dfrac{b-a}{2n}=\dfrac{h}{2}$
Strip $k$ is a trapezium with area $\dfrac{h}{2}[f(x_{k-1})+f(x_{k})]$
Add all $n$ strips. $f(x_{0})$ and $f(x_{n})$ appear once.
Every other $f(x_{k})$ is shared by two strips, so appears twice.
$\dfrac{h}{2}\{f(x_{0})+2f(x_{1})+\cdots+2f(x_{n-1})+f(x_{n})\}$

Use the trapezoidal rule with $4$ strips to estimate $\displaystyle\int_{0}^{1}e^{x^{2}}\,dx$. Give the answer to $3$ decimal places.
$\dfrac{b-a}{2n}=\dfrac{1}{8}$ and $x_{0},\dots,x_{4}=0,\,0.25,\,0.5,\,0.75,\,1$
$f(x)=e^{x^{2}}$: $1,\ 1.0645,\ 1.2840,\ 1.7551,\ 2.7183$
$\dfrac{1}{8}\{1+2.7183+2(1.0645+1.2840+1.7551)\}=\dfrac{1}{8}\times11.9255\approx1.491$

FactEpisode 12 · The trapezoidal rule
Curve concave up ($f''(x)\gt 0$): the estimate is too large.
Curve concave down ($f''(x)\lt 0$): the estimate is too small.
I DoEpisode 12 · The trapezoidal rule
Use the trapezoidal rule with $2$ strips to estimate $\displaystyle\int_{0}^{4}\sqrt{x}\,dx$. Is the estimate too large or too small? Check with the exact value.
$\dfrac{b-a}{2n}=\dfrac{4}{4}=1$ and $x_{0},x_{1},x_{2}=0,2,4$
$1\{0+2+2\sqrt{2}\}=2+2\sqrt{2}\approx4.83$
$\int_{0}^{4}\sqrt{x}\,dx=\left[\dfrac{2}{3}x^{\frac{3}{2}}\right]_{0}^{4}=\dfrac{16}{3}\approx5.33$
$f''(x)=-\dfrac{1}{4}x^{-\frac{3}{2}}\lt 0$, so the curve is concave down and the estimate is too small.
We Do 3Episode 12 · The trapezoidal rule
The shaded region is bounded by $y=\left(\dfrac{1}{2}\right)^{x}$, the coordinate axes and $x=2$.
a) Use two applications of the trapezoidal rule to estimate the area.
b) Show that the exact area is $\dfrac{3}{4\ln2}$.
c) Is the estimate too large or too small? Explain.
a) $\dfrac{b-a}{2n}=\dfrac{2}{4}=0.5$ and $x_{0},x_{1},x_{2}=0,1,2$
$0.5\left\{1+\dfrac{1}{4}+2\times\dfrac{1}{2}\right\}=0.5\times2.25=1.125$
b) $\int_{0}^{2}\left(\dfrac{1}{2}\right)^{x}dx=\left[\dfrac{(1/2)^{x}}{\ln(1/2)}\right]_{0}^{2}=\dfrac{\frac{1}{4}-1}{-\ln2}=\dfrac{3}{4\ln2}$
c) $\dfrac{3}{4\ln2}\approx1.082\lt 1.125$, so the estimate is too large. The curve is concave up.
HSC 2025 Q27(a)(b), with (c) added.
We Do 4Episode 12 · The trapezoidal rule
A particle moves in a straight line with velocity $v$ m/s at time $t$ seconds. It changes direction at $t=0.5$. Function values of $v$ are given correct to $2$ decimal places.
$\begin{array}{c|ccccc}t&0&0.25&0.5&0.75&1\\\hline v&-1.72&-1.03&0&0.51&0.63\end{array}$
Using the trapezoidal rule with four subintervals, find the approximate distance travelled in the interval $0\leq t\leq1$.
$v$ is negative for $0\leq t\lt 0.5$ and positive after, so find each part separately.
$0\leq t\leq0.5$: $\dfrac{0.5}{4}\{-1.72+0+2(-1.03)\}=0.125\times(-3.78)=-0.4725$, so the distance is $0.4725$
$0.5\leq t\leq1$: $0.125\{0+0.63+2(0.51)\}=0.125\times1.65=0.20625$
Distance $\approx0.4725+0.20625\approx0.68$ m
