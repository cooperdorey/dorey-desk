FactEpisode 2 · Sample spaces
A chance experiment is an action with a result that cannot be predicted, such as tossing a coin.
Each possible result is an outcome.
The sample space, $S$, is the set of all possible outcomes, written in braces $\{\ \}$.
Toss a coin:   $S = \{H,\ T\}$
List every possible outcome, each one only once.
