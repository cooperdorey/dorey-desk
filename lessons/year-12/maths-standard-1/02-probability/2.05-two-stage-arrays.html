FactEpisode 5 · Two-stage events: arrays
A two-stage event has two parts, such as tossing a coin and then rolling a die.
An array is a table of every pair of outcomes: first stage down the side, second stage across the top.
Number of outcomes $=$ rows $\times$ columns.
Each cell is one outcome. When each stage is fair, every cell is equally likely, so
$P = \dfrac{\text{number of cells that fit}}{\text{total number of cells}}$
