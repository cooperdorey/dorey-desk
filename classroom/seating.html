Seating chart

Upload a class list, click a name and then a desk to seat it, then save the plan or download it as an A4 PDF. The front is at the bottom.

To keep some students in place, click a seated name and press Lock (or use Lock seated). Shuffle the rest then spreads everyone else, seated or not, across the unlocked desks. Locked desks show a padlock. Upload the same classes.csv you use for attendance and pick a class from the list that appears; students marked as left are skipped. Otherwise, use an .xlsx or .csv with the last name in the first column and the first name in the second (or one column of "Last First"). Columns headed First name and Last name work in either order. The file is read in your browser and is never uploaded. Saving keeps the plan, with the student names, in this browser only; delete plans you no longer need with the × in the list.
