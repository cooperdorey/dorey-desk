Seating chart

Upload a class list, click a name and then a desk to seat it, then download the plan as an A4 PDF. The front is at the bottom.

Use an .xlsx or .csv with names in the first column, or with First name and Last name columns. The file is read in your browser; nothing is uploaded, and names are not saved, so reloading the page clears them.
